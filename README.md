# Superstore Sales Analysis Dashboard

## Project Overview
This project analyzes Superstore sales data to understand sales performance, profitability, product trends, customer segments, and regional performance.

The project uses Microsoft Excel, MySQL, and Power BI to prepare data, perform SQL analysis, and build dashboards that support data-driven business decisions.

## Project Objectives
- Analyze total sales, profit, and quantity sold.
- Identify top-performing products and sub-categories.
- Compare sales and profit across regions and states.
- Analyze performance by customer segment.
- Study monthly sales trends.
- Identify loss-making products.
- Explore the relationship between discounts and profit.
- Present business insights using dashboards.

## Tools & Technologies
- **Microsoft Excel:** Data preparation, PivotTables, charts, and dashboard creation.
- **MySQL:** SQL queries, aggregations, joins, subqueries, CTEs, and window functions where used.
- **Power BI:** Data modeling, DAX measures, and interactive dashboard development.

## Project Workflow
1. Reviewed and prepared the Superstore sales dataset.
2. Cleaned and checked the data for analysis.
3. Performed sales and profit analysis using MySQL.
4. Created an Excel dashboard.
5. Built an interactive Power BI dashboard.
6. Reviewed the results to identify business trends and insights.
